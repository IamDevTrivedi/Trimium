## What This Is

Trimium shortens URLs, generates QR codes, and tracks click analytics — all in one place. You can create short links with custom slugs, organize them into team workspaces, and see who clicked what, when, and from where. QR codes are customizable with your brand colors and logo, and you can export them in PNG, SVG, or PDF.

## How It's Built

### Frontend
Next.js 16, React 19, Tailwind CSS v4, shadcn/ui (Base UI), Zustand, React Hook Form + Zod, Recharts, motion

### Backend
Express 5, TypeScript, Mongoose, BullMQ (Redis), Cloudflare Turnstile, PoW rate limiting, SMTP (email via Nodemailer), Cloudinary (media)

### Infrastructure
MongoDB, Redis, Bun, Docker, GitHub Container Registry (GHCR)

## Key Features

- **URL Shortening** — custom slugs, branded domains, bulk upload
- **Analytics** — real-time click tracking, geo/devices/referrers, hourly & daily patterns
- **QR Codes** — customizable colors, logos, multiple download formats
- **Team Workspaces** — shared links, member invitations, role-based access
- **Auth** — email OTP, password policies, session management, Turnstile CAPTCHA
- **Security** — rate limiting, proof-of-work challenges, HTTP-only cookies
