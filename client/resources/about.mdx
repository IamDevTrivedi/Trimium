## What This Is

Trimium is a full-stack URL shortening and link management platform built as a portfolio project. It demonstrates modern web development patterns across a complete production-grade stack — authentication, analytics, team collaboration, QR code generation, and more.

## How It's Built

### Frontend
Next.js 16, React 19, Tailwind CSS v4, shadcn/ui (Base UI), Zustand, React Hook Form + Zod, Recharts, motion

### Backend
Express 5, TypeScript, Mongoose, BullMQ (Redis), Cloudflare Turnstile, PoW rate limiting, Brevo (email), Cloudinary (media)

### Infrastructure
MongoDB, Redis, Docker, Nginx, AWS EC2

## Key Features

- **URL Shortening** — custom slugs, branded domains, bulk upload
- **Analytics** — real-time click tracking, geo/devices/referrers, hourly & daily patterns
- **QR Codes** — customizable colors, logos, multiple download formats
- **Team Workspaces** — shared links, member invitations, role-based access
- **Auth** — email OTP, password policies, session management, Turnstile CAPTCHA
- **Security** — rate limiting, proof-of-work challenges, HTTP-only cookies
